# Project Audit — 2026-10-03

Scope: simulator logic and browser inputs, startup and recovery, fault policy, tests, build/deployment, current hardware direction, pricing, wiring relationships, enclosure and firmware prerequisites. Only `aeae1/Rock-Saw-Water-Control` is in scope. No machine firmware was flashed, hardware purchased, or physical measurements performed.

## Assessment

The operator-interface design is coherent and the verified simulator defects below have been corrected. The project remains a **tested simulation and engineering plan**, not field-ready hardware. The largest remaining risks are how the real actuator responds to failed/stale signals, whether its feedback proves position, and how the selected boards behave during resets and heat. Software tests cannot close those questions.

## Corrections to earlier simplification claims

Ten independent blue/white lamps require twenty color-power channels. One sixteen-channel PCA9685 cannot directly supply those twenty 12 V leads. Three PCB0046 high-side boards remain the current prebuilt direction; their cost is still unverified. SEN0262 is an analog receiver, not another I²C device. Its nominal 4–20 mA feedback voltage is 0.48–2.40 V. A shunt-only replacement is possible in a separately designed receiver, but adding a shunt in parallel with the existing receiver is not the selected circuit.

The wired proportional valve includes its own motor/controller and eliminates the proposed Tuya reverse-engineering path. It does not eliminate the current-command interface or position receiver. The four currently priced core items total $138.99; that is not a complete build. With the historical $25.99 lamp example, only $35.02 remains under $200 for everything else, so this prebuilt design has not demonstrated a sub-$200 total.

## Firmware and calibration handoff

The [firmware contract](../firmware/README.md) now records raw input acquisition, neutral qualification, reset precedence, bounded bus calls, explicit 4 mA startup, stale-output handling, a finite memory budget and unsigned timer rollover. The Nano Every has only 256 bytes of EEPROM; redundant calibration/settings and fault records must be designed to fit. MCU timing, storage endurance, actual watchdog behavior and compiled RAM use have not been tested by the browser suite.

The [flow curve plan](flow-calibration.md) remains unchanged in principle: measure through the actual hose/nozzles, use a validated monotone table and choose the nearest physical target on cap changes. Opening percentage and calibrated-flow percentage must remain separately labeled. Position feedback alone cannot diagnose a dry supply, blocked nozzle or hose leak. No invented calibration curve or measured-GPM claim has been added.

Next implementation work should begin with the bench acceptance sequence in the [build guide](build-guide.md) and record the measurements using [Validation](validation.md). Release firmware and final terminal-level wiring only after those results establish the electrical and actuator behavior.
